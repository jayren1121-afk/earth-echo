# Earth Echo

Earth Echo is a map-based data story for NASA Space Apps 2026 Taipei, in the challenge “Be An Earth System Trend Detective.”

Visitors can use **Tour mode** to hear NASA regional data at their location (or a point they tap on the map), or **Capital mode** to open precomputed records for about 50 capital cities.

This project is a hackathon prototype.

## Data sources

- NASA POWER
- MERRA-2 via Giovanni
- GPM IMERG
- GLDAS
- GRACE-DA
- OCO-2
- GISTEMP v4
- EONET
- NEX-GDDP-CMIP6
